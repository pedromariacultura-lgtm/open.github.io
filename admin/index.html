Token de Acesso

Crie um Personal Access Token no GitHub com acesso ao repositório.

  1. Vá em github.com/settings/tokens
  2. Clique em Generate new token → Fine-grained token
  3. Nome: OPEN Admin
  4. Expiração: escolha um prazo
  5. Repository access: Only select repositories → escolha open.github.io
  6. Permissions → Contents: Read and Write
  7. Clique em Generate token e copie o token gerado
Token ativo — alterações viram commits no repositório
